Technology

The challenge

The enforcement workflow depended heavily on manual review of camera footage. As traffic and camera volume increased, routine review created a growing processing burden and delayed enforcement.

What I built

  • Built a command-line automation tool to detect traffic violations from live camera feeds in real time.
  • Designed the Laravel backend to ingest, process and store high-frequency camera event data.
  • Built a responsive React dashboard for monitoring, filtering, replaying and exporting activity.
  • Automated challan generation and connected tickets to detected violations.
  • Refactored Eloquent queries and added database indexing for higher-throughput workloads.
  • Deployed the full-stack system on AWS with reliability and scale in mind.

Outcome

70%+ reduction in manual processing time
  • More than 70% reduction in manual processing time.
  • 35% improvement in data-pipeline throughput after ORM refactoring and query indexing.
  • High-concurrency camera feeds supported with no reported downtime.
